# Day 8: Built-in Functions / Interactivity

## Topics
- `mousePressed()` - runs once when mouse is clicked
- `keyPressed()` - runs once when a key is pressed
- `mouseDragged()` - runs repeatedly while mouse is pressed and moving
- `key` vs `keyCode` for detecting specific keys
