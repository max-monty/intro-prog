# Day 6: Unit 5 Quiz

## Topics Covered
- Class vocabulary: class, object, instance, constructor, instance variable, instance method
- Writing a class from a specification
- Reading a class and predicting what a sketch does
- Creating objects with `new`
- Calling instance methods on objects
- `void` methods vs. methods that return a value (especially `boolean`)
- `ArrayList` of objects: creating, looping, adding, removing
- Why backward loops are required when removing

---

## Format

- 42 points, 60 minutes.
- Part 1: 10 multiple-choice questions (20 points).
- Part 2: 3 free-response questions (22 points) — read a class, debug, write a class from scratch.
