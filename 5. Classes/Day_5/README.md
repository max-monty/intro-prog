# Day 5: Classes Culmination — Review

## Topics
- Class vs. object; constructors and `new`
- Instance variables (each object has its own)
- Instance methods: `void` vs. returning a value
- `boolean`-returning methods for yes/no questions
- `ArrayList` of objects and looping through them
- Spawning and removing objects on user input
- Backward loop for safe removal

---

## Why This Matters

Tomorrow is the quiz. The purpose of today is to close the gaps between recognizing code (reading a class and predicting what it does) and producing code (writing a class from a short specification). Both are tested.

---

## Common Errors to Practice Spotting

- Forgetting `new` when creating an object.
- Calling an instance method on the class name instead of an object (`Cat.meow()` instead of `c.meow()`).
- Writing a method as `void` when it needs to return something, or vice versa.
- Forward-looping while removing from an ArrayList — elements get skipped.
- Assigning to a local parameter instead of the instance variable in the constructor.
