## Activity: Iteration Art Gallery

Choose ONE project from the following options to create a polished piece of loop-based art. You will have the full period to work. Aim for at least Level 2.

### Project Options

1. **Recoding Schotter** - Recreate Georg Nees' classic 1968 artwork "Schotter": a grid of squares where the top rows are orderly and the bottom rows become increasingly random in position and rotation. Use nested for loops for the grid. Use `random()` with a range that increases based on the row number.

2. **Interrupted Grid** - Use nested for loops to draw a grid of identical shapes. On each iteration, use `random()` and an `if` statement to occasionally replace the normal shape with something different (a circle among squares, a colored shape among gray ones, a missing gap). The interruptions create visual rhythm.

3. **Iterative Pattern / Textile** - Design a repeating pattern suitable for wallpaper or fabric. Use nested loops to tile a motif across the canvas. Consider symmetry, rhythm, and color. The motif can be as simple as overlapping circles or as complex as a custom shape function.

4. **Moire Pattern** - Draw two overlapping sets of parallel lines (or concentric circles) using for loops. Offset one set slightly or connect it to the mouse position. The visual interference creates a shimmering moire effect.

5. **Checkerboard Plus** - Create a checkerboard using nested for loops and the modulo operator (`%`). Start with a standard 8x8 board, then customize it: add gradients across the board, make it interactive, or add a third color pattern.

6. **Personal Project** - Design your own loop-based artwork. Must use at least two for or while loops and incorporate at least two concepts from previous units.

### Levels

#### Level 1: Foundation
- Uses at least one for or while loop correctly
- Draws a visible pattern of 10+ repeated elements
- Clean code with descriptive variable names and comments

#### Level 2: Development
- Uses visual properties that change with the loop variable (size, color, position)
- Incorporates at least one concept from a previous unit (`random()`, conditionals, `mouseX`/`mouseY`, functions, `fill()`/color)
- Pattern shows intentional design choices

#### Level 3: Refinement
- Uses nested loops OR multiple loops working together
- Adds interactivity (mouse or keyboard changes the pattern)
- Shows creative experimentation beyond the basic prompt
- Code is well-organized with clear section comments

#### Level 4: Mastery
- Creates a visually compelling, polished composition
- Combines 3+ concepts from prior units into the loop artwork
- Uses techniques not explicitly taught (e.g., `%` modulo, `translate()`/`rotate()`, `pushMatrix()`/`popMatrix()`, `sin()`/`cos()` for circular patterns)
- Could be printed and hung on a wall
