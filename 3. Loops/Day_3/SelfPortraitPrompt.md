# Project: Self-Portrait – Bring Yourself to Life

In this project, you will create a **self-portrait** using code and add **motion**, **interactivity**, and/or **transformations**. Think of it as making your portrait **breathe, blink, move, or react**.

---

## Requirements

### Self-Portrait
- Create a recognizable **self-portrait** using shapes (ex: `ellipse()`, `rect()`, `line()`, `arc()`).
- Include **distinct features/details** (examples: eyes, pupils, eyebrows, hair, mouth, nose, ears, glasses, shirt, background elements, accessories).

### Animation
- Your portrait must include **animated changes**.  
  Examples:
  - blinking eyes
  - bobbing head
  - moving hair
  - pulsing background
  - changing facial expression over time

### Loops
- You must use **loops** (`for` loop and/or `while` loop) in a meaningful way.
- Your loop should create repeated visual elements.  
  Examples:
  - freckles
  - stars/sparkles
  - hair strands
  - shirt stripes/pattern
  - tiled background
  - confetti

### Variables
- Use both:
  - **Built-in variables** (use at least one): `mouseX`, `mouseY`, `frameCount`
  - **Your own variables** (at least two) that change over time (examples: `blink`, `angle`, `xOffset`, `pulse`, `mood`).

### Motion Techniques
Use one or more of the following:
- incrementing variables (`x += 1`, `angle += 0.05`)
- `random()` (carefully—avoid chaotic flicker unless intended)
- `map()` to scale values into visual ranges

### Interactivity
- Add at least one interactive feature using:
  - `mousePressed()`, `keyPressed()`, mouse hover, or mouse position  
  Examples:
  - press a key to change “mood”
  - click to toggle glasses/hat
  - move mouse to shift eyes or expression
